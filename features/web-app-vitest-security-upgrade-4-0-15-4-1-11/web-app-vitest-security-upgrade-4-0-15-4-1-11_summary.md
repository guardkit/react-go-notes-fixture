## Scope

This specification covers the dependency upgrade of `vitest` and `@vitest/coverage-v8` in the web app workspace (`apps/web`) from 4.0.15 to exactly 4.1.11, across both `apps/web/package.json` and the root `package-lock.json`, remediating critical security advisory GHSA-5xrq-8626-4rwp. It also covers the regression gate: the full existing test suite must run green under 4.1.11 with no new failures, errors, or skips, and the `@vitest/coverage-v8` coverage run must keep producing output in the same format and location so CI gates continue to function. No application behaviour changes are in scope; only test tooling versions change.
