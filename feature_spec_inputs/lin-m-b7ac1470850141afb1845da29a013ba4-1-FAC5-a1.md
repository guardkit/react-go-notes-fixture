The API handler (FEAT-PO-002) and the contract declaration (FEAT-PO-003) are mutually dependent: the handler emits what the contract declares, so they are best developed together and shipped atomically, with the contract listed second only because it is the artefact the next layer consumes. The regression slice (FEAT-PO-005) runs last as the gate that proves all three layers agree; it is cheap to write alongside the others but only meaningful once they exist.
